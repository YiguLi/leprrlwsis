# Critic 网络：当前结论清单

> 聚焦 actor-critic 里的 critic（评价网络）。每条都附实测依据与可复现工具，便于外部复核。
> 数据来源：`FULL-R2/AIFFLOR-run3`（v2, 178k 步）、`AUXFP`（1-step 辅助模型）、`PF1`（v2+`P(a,u)` 输入）、`v6`；工具 `agentutil/diag_probe_audit.py`、`agentutil/probe_cost_truth_grad.py`、`agentutil/probe_critic_health.py`。

## 一、已排除的原因（有证据）

| 候选原因 | 证据 | 判定 |
|---|---|---|
| 代码/求导链有 bug | 合成函数 `y=b(s)+Σw_j a_j`：恢复已知导数 **Pearson 1.0000**（无噪声）、0.9993（噪声 0.1）；autograd vs 自差分 **99.7%/99.9% 符号一致** | **排除** |
| 数据里"同状态附近没有动作变化" | 状态分箱内动作 std **0.069–0.091**（全箱 0.086–0.134）；`R²(a_j~s)` 仅 0.055–0.282 | **排除** |
| 网络容量/宽度/深度 | v1(14k)/v1af(19k)/v2(61k)/v3(96k)/v4(4k)/v5(17k)/v6(117k) 全部 48–52% 符号一致 | **排除** |
| 输出初始化 / 激活 / critic 学习率 | fan-in 让初始 `|dQ/da|` ×47；leaky 让逐样本梯度 ×3；lr 0.01→0.003。**符号一致率均不变** | **排除**（可影响幅值与稳定性，不影响方向） |
| 成本塔输入的是 clip 前动作（目标不一致） | 改 `cost_clip=1` 后目标一致，探针不变 | 已修，非病因 |
| λ 太小/太大 | 方向导数 `mean/sd`：cost 0.260、profit 0.005；λ 50→100/200/500 时该比值 **恒为 0.260** | **排除**（λ 不是杠杆） |
| `c1` 折点不可导 | 平滑（β=100,ε=0.05）把折线比值从 1.06× 提到 1.39×/2.02×，**符号一致率仍 49–52%** | 部分有效，非病因 |
| 喂 `P(a,u)` 特征（物理代理 R²=0.992） | 随机初始化时 `corr(∂Q/∂a, ∂P/∂a)` = **+0.346**；训练 54k 后 = **+0.016** | 方向注入有效，但**被训练过程抹掉** |

## 二、critic 现在到底错在哪（量化）

### 2.1 幅值：严重低估动作敏感度
| 对象 | 与"块级即时成本真值"的幅值比 `mean|∂|/mean|真值|` | 符号一致 | Pearson |
|---|---|---|---|
| critic_c（多步 Q，178k） | 0.614 | 49.5% | −0.018 |
| **aux_c（1-step，正确对齐口径）** | **0.061（小 16 倍）** | **52.3%** | +0.118 |

- 分风速：aux 在高风段（u∈[12,16)，20× 折线起作用处）`|真值|` 中位 **7.13** vs `|预测|` 中位 **1.04** ⇒ **小 7 倍**。
- 直接后果：高风段越限率 **42.6%**（低风 <1%）——critic 认为"降载没多少收益"。

### 2.2 逐样本梯度：方向近乎各向噪声
| 对象 | `M_j=mean|g|` | `A_j=|mean g|` | SNR=`A_j/std` | 样本间余弦均值 |
|---|---|---|---|---|
| critic | 10.8–16.7 | 0.13–5.39 | 0.007–0.19 | **+0.092** |
| aux | 0.66–1.10 | 0.05–0.40 | 0.028–0.33 | **+0.302** |

- 逐样本梯度幅值不小（10–17），但**均值只有它的 1–3%** ⇒ 绝大多数逐样本梯度在批次平均中相互抵消；
- 样本间余弦 ≈0.09（critic）/0.30（aux）⇒ 相邻样本的梯度方向几乎不相关。

### 2.3 存在"系统性偏置"，但尺度错
- critic 逐维正号比例：50.7 / 45.0 / **63.0** / **59.7** / 49.7%；
- aux 逐维：**66.3** / 54.7 / **39.3** / **64.7** / 55.3%。
⇒ 有偏但不等于真值方向，且幅值被压 16 倍。

### 2.4 值拟合很好，但那只说明"状态解释了大部分方差"
- aux：`L_c` 从 0.0296 → **4.9×10⁻⁴**（RMSE ≈2.2 MW·step），预测均值与目标均值差 0.1%；
- 同期动作在目标方差中只占 **30%**（风占 70%：`σ(ΔP_wind)=1.56 MW` vs `σ(ΔP_action)=1.03 MW`）；
- ⇒ **MSE 只约束"值"，完全不约束"导数"**；模型以"拟合状态均值"为最优解，动作支路被压平。这不是容量问题，是**损失函数不含导数信息**的问题。

### 2.5 一个反直觉但已复现的现象
- `P(a,u)` 输入在**随机初始化**时给出了正确的动作方向（`corr(∂Q/∂a,∂P/∂a)=+0.346`）；
- 训练 54k 步后降到 **+0.016** ⇒ **训练过程主动把这条正确通路关掉了**（因为它对"值"的贡献被状态项掩盖）。

## 三、由结论推出的 critic 改造方向（按优先级）

| 优先级 | 改造 | 针对的症结 | 预期判据 |
|---|---|---|---|
| **P0** | **导数正则/差分损失**（Sobolev）：在 MSE 之外加中心差分 Huber 损失，标签用配对反事实（同风速下 `a±δe_j`） | 幅值 0.061、MSE 不约束导数 | 幅值比 → 0.8–1.2；符号一致 → >85% |
| **P0** | **结构分解 + 折点层**：critic 只学光滑标量 `z≈ΔP`，`c1=|z|+20(z−3)⁺` 由结构/解析给出 | 折点两侧不可分辨（折线比 2.02 vs 29.4） | 折线比 → >20× |
| P1 | **目标中心化/残差学习**：`f_c` 拟合 `c1 − c1_ref(s)`（先训练状态-only 基线） | 动作只占 30% 方差 | 动作方差占比 → 接近 100% |
| P1 | **逐步目标**（每步一条，5 倍样本；块内 5 步各自确定） | 块级目标把块内风噪声积进来 | 值 RMSE 相对下降 |
| P2 | 采样按 `|ΔP|` 或 `|a−a_hold|` 加权（替代 TD 误差优先级） | 让"动作效应大"的样本主导梯度 | 大梯度子集符号一致 >80% |
| P2 | 逐状态尺度归一化 `∂ĉ/∂a ÷ |∂P/∂a|` | 跨状态幅值差 100 倍 | 批次梯度 SNR 提升 |

## 四、仍未解释、需要继续测的点

1. 为什么随机初始化时有效的 `P(a,u)` 通路会在训练中被压掉？是梯度尺度、初始化、还是"值损失不奖励它"？
2. 逐样本梯度近正交（cos 0.09）是"真值本身跨状态差异大"还是"网络在拟合状态特异的噪声"？（需用同一状态的重复采样检验）
3. 导数损失（P0）能否同时修好幅值与符号，还是只修幅值？
4. 多步 Q 的"价值导数"应如何对齐（探针 B：固定策略的有限 rollout + 共同随机数）——目前 critic 的 49.5% 不能直接判失败。

## 五、一句话结论

> **critic 的失败不是代码、数据、容量、λ 或折点问题，而是"损失只约束值、不约束导数"，叠加"目标方差被状态（风）占据 70%"——两者共同把动作支路压成一个幅值只剩 6% 的、方向近乎随机的偏置。**
