# Critic 动作梯度排查与改造指南

> 适用问题：critic 的成本预测误差较低，但 `∂Q_c/∂a` 或 `∂f_c/∂a` 与物理成本偏导接近随机；提高 λ、扩大网络、增加普通探索均未解决。
>
> 核心原则：**先保证评价对象一致，再验证偏导是否可辨识，最后修改模型与训练目标。不要先扩大网络或继续提高 λ。**

---

## 1. 问题定义与工作目标

需要区分三个不同目标：

1. **函数值拟合**：给定 `(s, a)`，准确预测成本或长期成本价值。
2. **即时物理偏导**：当前动作对当前块成本的局部影响。
3. **长期价值偏导**：当前动作通过即时成本、状态转移和未来策略对长期折扣成本的影响。

三者相关，但不等价。尤其不能默认：

\[
\frac{\partial Q_c^\pi(s,a)}{\partial a}
=
\frac{\partial c_{\mathrm{block}}(s,a)}{\partial a}.
\]

本指南的最终目标不是单纯提高函数值 R²，而是获得：

- 定义明确、可复现的动作梯度；
- 在独立测试集上可靠的梯度方向和幅值；
- 能推动策略降低真实成本的 actor 更新；
- 在相同环境和评价口径下缩小与离线参考解的差距。

---

## 2. 总体判断与排查优先级

当前现象优先指向以下问题，而不是网络容量不足：

| 优先级 | 候选问题 | 判断依据 | 首要验证 |
|---|---|---|---|
| P0 | 探针比较的不是同一个数学量 | 多步 `Q_c` 与即时 `c1` 被直接比较 | 统一目标、时间范围、动作版本和归一化 |
| P0 | MSE 不约束导数 | 1-step 模型值误差很低，符号一致率仍约 50% | 在独立数据上同时评估值误差和导数误差 |
| P1 | 普通数据中的动作效应被外生扰动淹没 | 风贡献主要目标方差，动作数据并非配对反事实 | 固定风序列做动作中心差分 |
| P1 | actor 接收到高噪声或相互抵消的梯度 | 逐样本梯度大，批次均值梯度极小 | 检查逐维符号、余弦相似度及聚合口径 |
| P2 | actor、clip、惩罚和对偶更新存在额外问题 | λ 顶格、原始动作越界、RL 与 DP 差距大 | 用物理真值梯度做 oracle actor 实验 |
| P3 | PER、target 滞后、Hessian 等训练因素 | 可能影响多步训练，但不能单独解释 1-step 失败 | 在 P0/P1 通过后再排查 |

## 3. 阶段 A：统一梯度探针口径

### 3.1 为每个探针登记完整定义

每次实验必须同时记录：

- 被微分对象：`c_step`、`c_block`、`Q_c` 或其他；
- 动作是原始 actor 输出、clip 后动作，还是环境实际执行动作；
- 状态是否为动作施加前状态；
- 微分发生在块首、块内每步，还是块级聚合后；
- 成本是求和、均值还是末步值；
- 是否乘 `1/s_c`、λ、γ 或折扣因子；
- 真值是否包含 `sign(ΔP)` 和越限分段；
- 平滑版与硬折点版是否混用；
- 求导时状态、风速、上一个出力是否保持固定。

任何一项不一致，都不能把符号不一致直接解释为 critic 学习失败。

### 3.2 分开建立两类探针

#### 探针 A：即时成本导数

用于验证 1-step 模型或即时成本网络：

\[
g^{\mathrm{true}}_{i,j}
=
\frac{c(s_i,a_i+\delta e_j)-c(s_i,a_i-\delta e_j)}{2\delta},
\qquad
g^{\mathrm{pred}}_{i,j}
=
\frac{\partial f_c(s_i,a_i)}{\partial a_j}.
\]

要求两边的成本定义、时间范围和归一化完全一致。

#### 探针 B：长期价值导数

用于分析多步 critic，但不再把即时成本导数当作唯一真值。可采用固定后续策略的有限 rollout：

\[
Q_c^{\pi}(s,a)
=
\mathbb E\left[\sum_{k=0}^{K-1}\gamma^k c_{t+k}
+\gamma^K V_c(s_{t+K})\right].
\]

使用相同外生随机序列，对动作做正负扰动，再比较有限差分与 autograd。后续策略必须冻结，避免把策略变化意外混入数值真值。

### 3.3 增加合成函数 sanity check

在真实环境实验前，用已知函数验证整个训练与求导流水线，例如：

\[
y(s,a)=b(s)+\sum_j w_j(s)a_j+\eta(s,a),
\]

先令 `η=0`，再加入可控噪声。检查：

- 网络是否能恢复已知导数；
- 训练集与测试集的梯度指标是否一致；
- autograd 与有限差分是否一致；
- 加入 batch、PER、归一化后是否仍一致。

**通过标准**：无噪声合成任务上，autograd 与有限差分的数值误差处于预定容差内，且训练后能恢复已知方向。

若合成任务失败，先修代码和测量，不继续调真实环境。

## 4. 阶段 B：重新评估数据可辨识性

### 4.1 不再只用动作标准差判断覆盖

动作标准差只能说明动作有变化，不能说明局部偏导可估计。按状态邻域统计：

- 有效样本数 `n_eff`；
- 每维动作标准差；
- 局部动作协方差矩阵；
- 协方差矩阵最小特征值和条件数；
- 动作与状态之间的相关性；
- 控制状态后，拟合目标的局部残差标准差；
- 训练集与测试集的状态—动作覆盖差异。

局部线性模型中，可用下式理解估计难度：

\[
\operatorname{SE}(\hat\beta_j)
\approx
\frac{\sigma_\epsilon}{\delta_j\sqrt{n_{\mathrm{eff}}}}.
\]

所需扰动或样本量应由“允许多大的导数标准误”反推，而不是统一规定动作 std 必须达到某个值。

### 4.2 建立条件可辨识性报告

按风速、上一出力、SOC 和电价分箱，每箱输出：

- 样本数；
- 动作协方差条件数；
- 局部值拟合 RMSE；
- 局部导数符号一致率；
- 真值梯度幅值中位数；
- 预测梯度幅值中位数。

重点比较高风与低风、越限附近与远离越限区域，不要只看全样本平均值。

## 5. 阶段 C：采集配对反事实数据

这是提高动作偏导信噪比的优先改造。

### 5.1 基本流程

对每个块首状态 `s`：

1. 保存完整环境状态和后续外生输入，包括各机组风速、SOC 相关状态、价格及 BESS 跟踪所需随机量。
2. 固定基准动作 `a`。
3. 对每个动作维度 `j`，分别执行 `a+δe_j` 和 `a−δe_j`。
4. 三个分支使用完全相同的风速序列和其他外生随机数。
5. 重放整个目标时间范围，计算对应成本。
6. 用中心差分获得即时或块级成本导数。

中心差分：

\[
d_{i,j}=\frac{c_{i,j}^{+}-c_{i,j}^{-}}{2\delta}.
\]

函数值目标可使用无扰动基准分支，避免把训练值目标人为改变为扰动分支均值。

### 5.2 δ 的选择

至少测试三个尺度，例如相对动作范围的小、中、大扰动。选择原则：

- 太小：数值误差、BESS 跟踪误差和环境噪声占主导；
- 太大：中心差分混入明显二阶项，不再代表局部导数；
- 靠近边界：使用可行域内的单边或缩短中心差分，并单独标记。

对每个样本记录实际 `δ_eff`，不能直接沿用名义 δ。

### 5.3 数据划分

按完整日期、风速序列或episode划分训练、验证和测试，避免同一状态的正负扰动分支被分到不同集合造成泄漏。

测试集必须包含：

- 未参与训练的状态；
- 未参与梯度损失计算的反事实分支；
- 高风、越限边界和低风等不同区域。

## 6. 阶段 D：修改模型与训练目标

### 6.1 不再只优化 MSE

基础值损失：

\[
\mathcal L_{\mathrm{value}}
=
\operatorname{MSE}(f_c(s,a),y_c).
\]

可加入有限差分损失：

\[
\widehat d_{i,j}
=
\frac{f_c(s_i,a_i+\delta e_j)-f_c(s_i,a_i-\delta e_j)}{2\delta},
\]

\[
\mathcal L_{\mathrm{diff}}
=
\operatorname{Huber}(\widehat d-d).
\]

总损失：

\[
\mathcal L
=
\mathcal L_{\mathrm{value}}
+\alpha_{\mathrm{diff}}\mathcal L_{\mathrm{diff}}.
\]

差分损失通常比直接对 autograd 导数做二阶反向传播更稳定，也更容易检查。

### 6.2 必要时再加入导数损失

若已确认物理中心差分足够局部，可使用：

\[
\mathcal L_{\mathrm{grad}}
=
\operatorname{Huber}
\left(
\frac{\partial f_c}{\partial a},g^{\mathrm{true}}
\right).
\]

注意其计算成本和二阶反向传播开销。先用差分损失，只有在差分损失不足时再尝试。

### 6.3 使用硬连接的物理结构

与其只把 `P(a,u)` 当作普通输入，优先考虑：

\[
\widehat c
=
h\left(P(a,u)-P_{G,\mathrm{prev}},P_F,u,\mathrm{SOC},\mathrm{price}\right)
+r_\theta(s,a),
\]

或让网络只学习已知解析成本之外的残差。

要求：

- 解析功率通路可微；
- actor 与 critic 使用同一个实际执行动作；
- 残差网络不能无约束地破坏已知物理方向；
- 解析代理与 FLORIS 的系统性误差单独评估。

### 6.4 拆分成本通道

将当前成本拆成两个目标分别学习：

\[
c_{\mathrm{vol}}=|P_G(t)-P_G(t-1)|,
\]

\[
c_{\mathrm{over}}=20(P_F-3)^+.
\]

优点：

- 波动成本和越限成本具有不同折点；
- 可分别选择平滑方式和采样权重；
- 能判断错误主要来自绝对值换符号还是越限分段；
- actor 可明确检查两个通道的梯度贡献。

## 7. 阶段 E：诊断 actor 实际收到的梯度

### 7.1 统一梯度统计口径

对同一批样本、同一动作版本，同时记录：

\[
M_j=\frac1B\sum_i|g_{i,j}|,
\qquad
A_j=\left|\frac1B\sum_i g_{i,j}\right|.
\]

另外记录：

- 每维梯度均值、标准差和符号比例；
- 样本间梯度余弦相似度；
- 每维 `mean/sd`；
- actor 参数更新前后的范数；
- profit 与 cost 梯度的夹角；
- clip 前后动作差异及其梯度路径。

不能用一个“逐样本全维范数均值”与一个“批次聚合标量导数”直接比较并得出结论。

### 7.2 正确理解 λ

λ 会同时放大成本梯度均值与标准差：

\[
\operatorname{SNR}(\lambda g)=\operatorname{SNR}(g).
\]

因此：

- λ 可以改变确定性目标中的成本权重；
- λ 不能修复梯度方向错误；
- λ 不能提高固定梯度分布的信噪比；
- λ 长期顶格时，应视为约束优化未正常调节的信号。

只有在梯度方向验证可靠后，才继续调 λ 范围、对偶学习率和约束尺度。

## 8. 阶段 F：oracle actor 判别实验

该实验用于区分“critic 梯度瓶颈”和“actor/约束优化瓶颈”。

### 8.1 实验组

至少保留以下组别：

1. **Baseline**：当前完整训练流程。
2. **Value-only**：仅使用值 MSE 的成本模型。
3. **Diff-supervised**：值损失加配对差分损失。
4. **Oracle-gradient**：用经过口径验证的物理梯度替代相应 critic 动作梯度。
5. **Physics-fixed**：固定解析物理通路，仅学习必要残差。

除目标改动外，尽量保持数据、随机种子、训练步数和 actor 设置一致。

### 8.2 结果解释

- Oracle 明显优于 baseline：成本动作梯度是重要瓶颈。
- Diff-supervised 接近 oracle：差分监督是有效改造。
- Oracle 仍无法改善：重点检查 actor 参数化、clip、奖励尺度、探索、对偶更新和多步信用分配。
- 梯度指标改善但行为不改善：检查长期价值梯度、策略更新稳定性和执行动作一致性。
- 函数值误差改善但梯度不改善：再次说明 MSE 与导数学习解耦。

## 9. 评价指标与通过标准

### 9.1 函数值指标

在独立测试集上报告：

- MSE、RMSE、MAE；
- 按风速和越限状态分组的误差；
- 均值偏差；
- 大成本样本误差；
- 两个成本子通道的独立误差。

### 9.2 梯度指标

至少报告：

- Pearson 与 Spearman；
- 符号一致率；
- 大梯度子集符号一致率；
- 梯度幅值比和中位相对误差；
- 越限/非越限区域的梯度幅值比；
- 各动作维度分别统计；
- 中心差分尺度的敏感性；
- autograd 与模型有限差分的一致性。

不要只报告五维合并结果，因为维度之间可能相互抵消。

### 9.3 行为指标

在相同代表日或固定测试风速池上报告：

- `η`；
- 越限率；
- 总成本与总收益；
- 原始及归一化目标 `J`；
- λ 曲线；
- 高风与低风分组指标；
- 与统一降载 DP 参考解的差距。

### 9.4 建议的实验推进门槛

阈值应先用合成任务和 oracle 结果校准。流程上采用以下门槛：

1. 探针口径未统一：不比较模型优劣。
2. autograd 与模型自身有限差分不一致：不进入物理真值比较。
3. 只在训练集梯度良好、测试集失败：按过拟合处理。
4. 梯度没有稳定优于 baseline：不进入长时间 RL 训练。
5. 短程 oracle 实验没有行为收益：不继续单纯扩大 critic 或提高 λ。

## 10. 推荐实验顺序与停止条件

### 第一轮：低成本验证

- [ ] 统一即时成本探针口径。
- [ ] 增加合成函数 sanity check。
- [ ] 检查 autograd 与模型有限差分。
- [ ] 重新统计逐样本与批次梯度，确保口径一致。
- [ ] 输出分状态、分维度的可辨识性报告。

**停止条件**：以上任一项存在实现错误，先修测量，不运行新的长训练。

### 第二轮：验证核心假设

- [ ] 用公共随机数生成小规模配对反事实数据集。
- [ ] 比较普通 MSE 与 MSE+差分损失。
- [ ] 在独立测试集上评价函数值与导数。
- [ ] 比较不同 δ 和不同风速区域。

**停止条件**：若配对数据仍不能恢复即时导数，检查状态完整性、成本实现、BESS 跟踪和物理中心差分定义。

### 第三轮：验证行为价值

- [ ] 运行短程 oracle actor。
- [ ] 运行 diff-supervised critic。
- [ ] 与 baseline 使用相同测试日比较行为指标。
- [ ] 检查 λ、clip 和 actor 更新是否仍有独立异常。

**停止条件**：若 oracle 也无收益，暂停 critic 改造，转向 actor 与约束优化排查。

### 第四轮：多步 critic 与完整训练

- [ ] 将已验证的即时成本结构接入多步 critic。
- [ ] 单独测量长期价值的有限 rollout 导数。
- [ ] 再评估 PER、target 网络滞后和 UTD。
- [ ] 最后才进行网络容量、学习率和 λ 范围搜索。

## 11. 每次实验必须保存的日志

建议每次运行至少保存：

- 配置、代码版本、随机种子和数据集版本；
- 探针对象及完整数学定义；
- 动作 clip 与环境执行动作的一致性检查；
- 值损失的训练/验证/测试曲线；
- 梯度指标的训练/验证/测试曲线；
- 每个动作维度的梯度统计；
- 差分扰动尺度及有效扰动尺度；
- 风速、越限和SOC分箱结果；
- actor 更新范数和 profit/cost 梯度夹角；
- λ、越界率、η、成本、收益与 DP 差距；
- 配对反事实样本的环境重放校验结果。

---

## 12. 明确不推荐的做法

在核心探针和配对实验通过前，不建议：

- 继续单纯增加 critic 层数或参数量；
- 把 λ 从 50 继续提高到 100、200、500 作为主要修复；
- 只根据动作 std 增大就认定覆盖充分；
- 只根据 MSE 降低就认定 critic 学到了物理；
- 只用随机初始化时的梯度相关性判断特征有效；
- 将多步 `Q_c` 与即时 `c1` 的符号一致率当作唯一梯度真值；
- 在训练集上计算梯度指标后直接宣布成功；
- 同时改变网络、采样、损失、λ 和 actor，导致无法归因。

## 13. 最终决策树

```text
探针口径是否一致？
├─ 否：修探针，停止模型比较。
└─ 是
   ├─ autograd 与模型有限差分是否一致？
   │  ├─ 否：修求导、动作连接或归一化。
   │  └─ 是
   │     ├─ 合成函数能否恢复导数？
   │     │  ├─ 否：修训练与采样流水线。
   │     │  └─ 是
   │     │     ├─ 配对反事实+差分损失能否改善独立测试梯度？
   │     │     │  ├─ 否：检查状态完整性、环境重放、目标定义。
   │     │     │  └─ 是
   │     │     │     ├─ oracle actor 能否改善行为？
   │     │     │     │  ├─ 否：转向 actor、clip、对偶和多步信用分配。
   │     │     │     │  └─ 是：将差分监督/物理结构接入完整训练。
```

## 14. 最小可行改造方案

如果只能先做一组改动，采用以下组合：

1. 仅针对 **1-step、块级即时成本**建立严格对齐的探针。
2. 固定环境状态与后续风速序列，为每个动作维度采集正负扰动分支。
3. 保持原值 MSE，增加中心差分 Huber 损失。
4. 在完全独立的日期上报告分维梯度指标。
5. 用短程 oracle actor 判断梯度改善是否能转化为行为收益。

这组实验能够以最小成本回答最关键的问题：**当前失败究竟来自动作偏导不可辨识、普通 MSE 不学导数，还是 actor 即使获得正确梯度也无法优化。**
