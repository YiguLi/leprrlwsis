# 问题简报：critic 无法学到"动作 → 波动成本"的偏导（只列现象）

> 目的：把已观测到的现象与测量数据完整列出，供外部判断。
> 本文件**不做因果推断、不给结论**，所有"数值"均为实测，末尾只列未解释的现象。

## A. 任务与环境（事实）

- 风场 5 台机组串列；FLORIS（`AifflorPhysics(nt=5, calibrated=False, power_scale=LEVEL_COEF)`）。
- 上层（H）动作 6 维：`a_1..a_5 ∈ [0, 0.5]`（轴向诱导因子），`g` = 块总放电量（MW·min，可行域 `[-C_max, +D_max]` 随 SOC 变化）。
  上层每 **5 步（一个块）** 决策一次。
- 下层（L）动作 1 维：BESS 功率（每步），需跟踪上层给的 `g`。
- 一天 = 1440 步；电价三档 300 / 580 / 980 元/MWh 按日程切换。
- 风速池：默认 `FFC_speed_noise_1.csv`（在实测序列上加白噪），`σ(Δu) = 1.42 m/s`；
  另有 clean 池 `FFC_speed_1.csv`，`σ(Δu) = 0.063 m/s`。
- 出力：`P(a,u) = c·u³·Σ_i 4a_i(1−a_i)²`。用该式对 FLORIS 实测出力做无截距回归：**R² = 0.992，平均相对误差 3.4%**（标定系数 `k = 1.357e-3`）。
- 奖励：`r1 = pr·P_G·dt − pen5 − pen6`，`P_G = ptur − pbrule`；`pen5 = κ·Σ max(0,−a)+max(0,a−0.5)`（κ 默认 100），`pen6` 为 `g` 出可行域的线性罚（系数 10）。
- 成本：`c1 = |P_G(t) − P_G(t−1)| + 20·(P_F−3)⁺`（另有可选平滑版，见下）。
- 对偶：`λ1` 物理价 `∈ [2, 50]` 元/(MW·step)，初值 2；归一化尺度 `s_p = 1000`（r1）、`s_c = 100`（c1）。
- 训练设置（大多数运行）：critic lr 3e-3、actor lr 1e-4、`utd_h=4`、`bsize=256`、`rmsize=4e4`、`γ=0.95`（块级）、`τ=1e-3`、PER（α 0.6、β 0.4→1）、warmup 7200 步（LHS 覆盖 [0,0.5]）、探索噪声 ±0.05 并于 step 115 200 归零。
- critic v2（默认）：`s: 4→16→100` ∥ `a: 6→32→64` → `cat 164 → 164(残差) → 128 → 64 → 1`（60 617 参数）；
  actor：`4→16→100→16→6`（3 498 参数）。

## C. 已做的测量与数值

### C1. 数据覆盖（是否存在"同状态下动作无变化"）
- 状态分箱（u 按 1 m/s、log P_G 0.25、SOC 0.1）：286 箱，99% 的箱样本 ≥20。
- **箱内动作标准差**（中位）：`0.072 / 0.082 / 0.091 / 0.084 / 0.069`（5 维）；全箱 std 为 `0.107 / 0.091 / 0.134 / 0.105 / 0.086`。
- `R²(a_j ~ 状态一次+二次项)`：`0.182 / 0.071 / 0.282 / 0.162 / 0.055`。
- `corr(P_G(t), P_G(t−1)) = 0.962`；`R²(P_G(t) ~ 动作) = 0.85~0.99`。

### C2. 动作偏导的"真值对照"（核心测量）
方法：在块首步样本上，用 FLORIS 物理做中心差分得 `∂P/∂a_j`，按
`∂c1/∂a_j = (1 + 20·1{P_F>3}) · sign(ΔP) · ∂P/∂a_j`（与 `--c1_smooth` 同口径）构造真值；
与 critic 的逐样本 autograd `∂Q_c/∂a_j` 比较。样本 600 条。

| checkpoint | 符号一致率 | Pearson | Spearman | 折线比值（越限/非越限 \|梯度\|） | 真值折线比值 | vs `∂P/∂a` 的 Pearson |
|---|---|---|---|---|---|---|
| v2 (run3, 178k) | 48.9% | 0.037 | 0.017 | 1.06× | 52.4× | −0.115 |
| v6 (143k) | 51.6% | −0.053 | 0.004 | 1.19× | 26.6× | −0.168 |
| 1-step 辅助（9k） | 50.0% | −0.020 | 0.007 | 1.05× | 28.4× | — |
| 1-step + `P(a,u)`（12k） | 51.8% | 0.039 | 0.055 | **2.02×** | 29.4× | — |
| PF1（v2+`P(a,u)`，54k） | 49.2% | −0.014 | 0.005 | 1.39× | 58.4× | **+0.016** |
| PF1 在 5k（未训练，随机初始化） | 53.7% | 0.182 | 0.087 | 1.20× | 44.1× | **+0.346** |

- 大梯度子集（|真值| > 中位）的符号一致率：v2 46.5%、1-step+特征 55.9%。
- 逐维相关（1-step+特征）：dim0 +0.252、dim1 −0.180、dim2 +0.147、dim3 +0.154、dim4 +0.146。

### C3. 逐样本梯度 vs 批次均值梯度
- 逐样本 `mean|∂Q_c/∂a|`：**≈ 44**（normalized Q 单位/单位 a）。
- 用 `q.mean()`（批次均值）求导得到的 `|∂Q/∂a|`：**≈ 8.8×10⁻⁴**。
- 两者相差约 **5 个数量级**。

### C4. 沿"5 维同时 +δ"方向的方向导数统计（run3，800 条块首样本）
| 通道 | mean | sd | mean/sd |
|---|---|---|---|
| profit `Σ∂Q_p/∂a` | +0.17 | 32.95 | 0.005 |
| cost `Σ∂Q_c/∂a` | +7.49 | 28.87 | 0.260 |
| **真值** `Σ∂c1/∂a` | +2.32 | 24.80 | 0.094 |
| 1-step+特征 `Σ∂f_c/∂a` | +0.084 | 1.569 | 0.053 |

- 把 λ 从 50 改到 100/200/500（纯算术）：`λ·mean` 与 `λ·sd` 同比放大，`mean/sd = 0.260` **不变**。

### C5. 1-step 监督模型（无 bootstrap、无 target 网络）
- 结构 `[4+6]→64→64→1`，MSE 对 buffer 里的 `r1/s_p`、`c1/s_c`。
- `L_c`（c1 的 MSE）从 0.0296 降到 **4.9×10⁻⁴**（≈ RMSE 2.2 MW·step）；`f_c` 均值与目标均值差 0.1%（0.2368 vs 0.2366）。
- 目标 `c1`（块级）的均值 18.85、标准差 33.92、范围 [−0.3, 285.8]。
- 该模型的 `∂f_c/∂a` 与真值的符号一致率 **50.0%**（见 C2）。

### C6. 目标方差中"风"与"动作"的分解（run3，3 万个块）
- `σ(Δu) = 1.417 m/s`，平均 `dP/du = 0.97 MW/(m/s)` ⇒ **风驱动 ΔP 的 σ = 1.56 MW**。
- 平均 `|∂P/∂a_i| = 3.59 MW/单位`，块间 `Σ|Δa| = 0.157` ⇒ **动作驱动 ΔP 的 σ = 1.03 MW**。
- 方差占比：**风 ≈ 70%，动作 ≈ 30%**（风的方差是动作的 2.3 倍）。

### C7. 值函数的 TD 残差（`update_stats_H.csv` 末 500 次更新）
- run3：`td_p_mean / q_p_mean = 28%`，`td_c_mean / q_c_mean = 24%`。
- v6：21% / 19%。

## E. 尚未解释的现象（仅提问）

1. 在"`r1`、`c1` 被 `(s,a)` 完全决定"（除 BESS 跟踪误差）的前提下，为什么一个 1-step 监督模型能把 `c1` 拟合到 `L_c=4.9e-4`，却仍然只有 50% 的 `∂c1/∂a` 符号一致率？
2. 数据里同一状态附近的动作方差（箱内 std ≈0.07–0.09）是否足够估计 5 维偏导？若不够，需要多大？
3. 逐样本 `|∂Q_c/∂a|≈44` 与批次均值 `≈8.8e-4` 相差 5 个数量级，这个差异说明什么？
4. 目标方差中动作只占 30%（风占 70%），在这样的信噪比下，是否存在"让偏导可辨识"的训练方案？需要什么样的目标变换/损失/采样？
5. `P(a,u)` 作为输入在随机初始化时能把 `corr(∂Q/∂a, ∂P/∂a)` 提到 +0.35，训练后却降到 +0.016——训练过程中发生了什么？
6. 成本通道的方向导数 `mean/sd = 0.26`、利润通道 `0.005`，而 λ 从 50 提到 500 时该比值不变。λ 是否是有效杠杆？
7. 离线 DP（仅整场降载）在 λ=50 给出 η 0.501 / 越限 0.1%；实际 RL 在 λ=50 顶格时 η 0.70~0.91 / 越限 7~14%。这个差距属于"策略表达/优化"问题，还是"梯度不可辨识"问题？
8. 是否存在我尚未测量的量（例如 critic 对 `a` 的 Hessian、逐状态的条件可辨识性、PER 的采样偏置、target 网络的滞后）能够解释上述全部现象？
