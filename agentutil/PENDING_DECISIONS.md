## §1 高优先：有实验证据、且影响结论

### D1 · 给 H 层 actor 输出加界（原 E2）
**证据**：① Q 峰实测 **60–80% 落在带内**（与 `model.py:72-91` "最优解恰在边界、故输出层不做 squash" 的立论矛盾）；② 容量 A/B 里 256/256 的 actor 跑到带外 **−3.99…+5.63**，越界罚爆炸到 **6323 元/块**；③ 256/256+lr0.001 **永久发散**（越界 47.5%、罚 8,725、q_p −51,456）。
**选项**
* **V3 线性核心 + tanh 软尾巴**（带内 `a=z` 梯度恒 1、带外 `bound+m·tanh((z−bound)/m)`）：越界**上界 = m**；**无需重导 bias-init**（带内是恒等 ⇒ warmup"同分布"不变量原样成立）；保留罚通道但封顶。`m = margin_rel·带宽`，建议 `margin_rel ∈ {0.01, 0.04}`。
* V1 标准 squash（`lo+(hi−lo)·σ(z)`）：越界 = 0，但**必须重导 `init_wt_action_bias`**（否则初始动作 ≈0.52–0.71 直接越界），且 `penalty_NN_H` 变死代码。
* 不做。
**建议**：V3 + `margin_rel 0.04`，**只先改 aifflor 一条链路**，与基线配对 30k；判据 = 越界率→有界、罚上限、发散消失（**几何指标不会改善**，那是 critic 侧的事）。
**代价**：动作语义改变 ⇒ 新旧 run 不可比（罚/越界列尤甚）；不改则发散与罚爆炸风险留在库里。

### D2 · `nstep` 10 → 1？
**证据**：16/100 下 nstep1 与 nstep10 **打平**（配对逐日差 −2,903，t=−1.3）；64/128 下 nstep1 **显著更好**（差 10,826±2,778，t≈3.9）；nstep1 的末端 TD 误差 **0.13–0.32 vs 0.78–1.29**（低 4–6×）；目标方差 ∝√n。
**选项**：改默认 1（旧 run 传 `--nstep 10` 复现）／保持 10／先补 3–5 seed 复核。
**建议**：先补 seed 复核再改；`nstep` 是**纯训练侧**参数（评测端 0 处引用），改动风险低。
**状态（2026-10）**：**已部分落地 —— 默认值先由 10 改为 5**（全 11 个 `*_main.py`，
脚本 `agentutil/port_nstep_default5.py`，附录取根 `README.md`）；"→ 1" 仍未采纳，
本项继续挂着等 seed 复核。

### D3 · 探索口径落地（E1 的结论）
**证据**（4 臂 × 30k 配对）：WT 恒定 0.05 ⇒ **−14,082/天（t=−4.3）**；恒定 0.10 ⇒ **−18,847/天（t=−6.0）**；而 **WT 恒定 0.05 + 信号恒定 0.03**（E1c）⇒ **+4,496/天（名义最好）**、罚最低（21.4 元/块）、越界最低（4.4%）；**E1c − E1a（只差信号日程）= +18,577/天（t≈4.0）**。且可辨识性对剂量**零响应**（P(∂Q/∂a<0) 恒 0.47–0.56）。
**结论**：① **WT 保持现有衰减日程**（加大有害）；② **信号维改成"小且恒定"**（`--sig_noise_max 0.03 --sig_noise_min 0.03`）是唯一有正面证据的改动。
**建议**：采纳 ②，① 不动；③ 需再补 seed（单 seed）。

### D4 · H/L 共享参数解耦
**证据**：`wt_noise` 被 ddpg 的 **L 分支**复用（`else: amp_e = np.full(n, self.wt_noise)`）；`--rate/--prate` 是 **H 与 L 共用一个 lr**；⇒ 调 H 会静默改 L（td3prrbb/td3prle 因死接线尤其危险）。
**选项**：拆出 `l_noise_rel/l_noise_floor` 与 `l_rate/l_prate`（代码改动）／保持共享但在 main 里无条件覆写。
**建议**：拆（这是本轮两次踩到同一类耦合的根因）。

### D5 · 容量口径确认（16/100）
**证据**：匹配晚窗三条容量臂**几乎重合**（+272.3 / +277.0 / +262.5 元/块），但累计代价天差地别（+141.6 / +107.0 / **−7.8**）；∂Q/∂a 可辨识性对容量**零响应**（dQ/TD 恒 ≈0.4）；256/256 慢 19% 且曾发散。

## §5 PAVE 首轮结论（**预言前半成立、后半被否证**）与新增决策项

> ⚠ **口径修正（重要）**：本节初版用的是**单个 checkpoint（26000）**的几何数。事后发现单 ckpt 的翻转率噪声达 **±3–9pp**、PAVE 的负定性率在 26000 上读到 10.4% 却**不可重复**（多点平均只有 2.6%）⇒ 下表用**多 checkpoint 平均**（16k/20k/24k/**28k**、每点 250 样本，给出 ±sd）。**最重要的更正：μ 侧（负定性率）其实没被修好。**

**结论 1（M 侧机制）成立且稳健**：翻转率 **34.9 ±6% → 7.8 ±7%（PAVE）/ 13.8 ±6%（VFC）**，mean cos 0.177 → **0.627**，**跨维同号率 49.9% → 66.7%**（把"5 台机组梯度场互不相干"那个病治好了）。而**只换激活无效**（SILU 38.1 ±5% ≈ BASE 34.9 ±6%，且 SILU 单因子成绩显著更差）⇒ 起作用的是**正则**，不是 SiLU。
**结论 1b（μ 侧）❌ 没修好 —— 对初版的重要更正**：负定性率 **0.4 ±0% → 2.6 ±2%**（PAVE，仍在基线 ±1sd 附近），单 ckpt 26000 上的 10.4% **不可重复**。⇒ Curv（权重 0.0056）**太弱**，"把 μ 顶住"根本没实现 ⇒ 这正是 CURV4X / CURVONLY 两条臂要验的。
**结论 2（成绩）否证**：PAVE 的 r1/块 **106.8（基线 184.2，−42%）**、日 r1 **−21,362（t=−1.1，不显著但方向一致）**；SILU 单因子 **−5,129/天（t=−2.6，显著）**；VFC **灾难性发散**（r1/块 −12,879、罚 13,044 元/块、越界 43.0%、TD 19.67、t=−3.3）。
**结论 3（根因，来自 `pave_stats.csv`）**：
* **VFC/MPR 按"当前 batch 的 ‖∇_aQ‖²"归一化 ⇒ 损失对梯度整体尺度不变** ⇒ 它**无法阻止、反而纵容**梯度塌到 0（VFC 臂：‖∇_aQ‖² 603 → **5.4e−06**，TD 1.20 → **19.67**）。⚠ 因此 VFC 的"低翻转率"**部分是退化假象**（梯度近 0 时符号近乎噪声）—— **该臂的几何读数不可解释，只有 TD 说明问题**。
* **Curv 贡献随训练衰减到 ~0**（curv 53 → 0.089，权重固定 0.0056 ⇒ 加权贡献 **0.0003**）⇒ 守卫恰好在最需要时失效（与结论 1b 一致）。
* 几何步与 TD 拟合**相互拉扯**（TD 1.20 → 2.21）。
**结论 4**：新 warmup 口径对几何**无实质影响**（34.9 ±6% vs 旧口径 31.8 ±2%，落在 sd 内）⇒ §4 的口径改动不是这些现象的原因。
**结论 5（方法论教训，写进以后所有几何实验）**：几何指标**必须多 ckpt 平均**（单点噪声 ±3–9pp），且**必须同时看 ‖∇_aQ‖² 与 TD** —— 否则"翻转率降了"可能是**梯度塌陷**造成的假象（VFC 臂就是这个陷阱）。

### 5.2 新增决策项

* **D14 · 归一化口径（推荐优先）**：把 MPR/VFC 的分母从"当前 batch 的 ‖∇_aQ‖²"改为**detached 的慢速 EMA 参考尺度**（或固定常数），使损失**不再对梯度整体尺度免疫**，从而能真正阻止塌陷。
* **D15 · Curv 的加权/替代**：① 把 `--pave_w_curv` 按参考尺度**调度**（或自适应地盯负定性率目标值）；② 或改用**有限差分凹性罚** `max(0, (Q(a+ε)−2Q(a)+Q(a−ε))/ε² + δ)` —— **无需二阶导、ReLU 也能用**，且天然带尺度 ⇒ 可**同时摆脱"必须 silu"的约束**（实测 silu 单因子显著变差）。
* **D16 · 是否继续投 PAVE 线**：机制成立但成绩否证。三条路：(a) 按 D14+D15 再试一轮（推荐，代价 ~2×30k）；(b) 只保留几何诊断工具、**不把 PAVE 并入正式方法**；(c) 归档该臂。

### 结论（**含两条对 §5 建议的翻转**）

0. 🎯 **最重要的一条：真正预测成绩的是 μ（动作方向凹性），不是翻转率**。
   11 条臂按"μ ≥ 20%"一刀切开，**完全可分**：
   * **μ ≥ 20% 的三条臂全部正收益**：CURV4X μ20.4% ⇒ **+3,247（t+2.1）**、CURVONLY μ34.1% ⇒ **+2,620（t+2.0）**、EVERY4 μ75.7% ⇒ **+3,009（t+1.5）**；
   * **μ ≤ 2.6% 的八条全部 ≤0**（唯一的例外是**旧 warmup 口径**的参照臂 AB-H16N10：μ2.5% ⇒ +2,333，t=1.6 不显著，且它是唯一既非 silu 又用旧口径的臂）：BASE μ0.4%（参照 0）、SILU μ1.6% ⇒ −5,129、PAVE μ2.6% ⇒ −21,362、VFC μ0% ⇒ −3.96e6、MPR μ0% ⇒ −3.50e6、NOVFC μ0% ⇒ −8,984、**NOCURV μ0% ⇒ −257,008（t=−3.7）**。
   * 而**翻转率根本不预测成绩**：翻转率最低的三条（MPR 6.5%、NOVFC 18.1%、VFC 13.8%）恰好是灾难臂；最好的 CURVONLY 翻转率 30.1% 与基线 34.9% 几乎一样。
   ⇒ **"翻转率下降 ⇒ 成绩改善"这条因果链在本任务上不成立**；成立的是 **"μ 抬高 ⇒ 成绩改善"**。原因也清楚：低翻转率有两种来源 —— **真正平滑的场**（好）与**梯度被压塌的退化场**（坏），单看翻转率无法区分（VFC/MPR/NOVFC 就是退化那一类，gscale 1e−6~1e−7、TD 19.7/39.7/1.85）。**μ 是无量纲的"信号可分辨度"，它同时要求梯度不塌，因此才是有效判据。**
1. ✅ **预言后半成立 —— 但只在"含 Curv 且剂量足够"的变体上**：**CURV4X +3,247/天（t=+2.1）**、**CURVONLY +2,620/天（t=+2.0）**、**EVERY4 +3,009/天（t=+1.5）**，罚更低（8.9–21.1 vs 12.8）、越界更低（CURVONLY 1.79% vs 3.79%）、**CURVONLY 的 critic 拟合还最好（TD 1.10 < 基线 1.20）**。⇒ 我 §5 里"PAVE 线不值得投"的判断**作废**。
2. ✅ **原 PAVE 臂的 −21,362 是"剂量/步数"问题，不是目标函数问题**：同一套权重把几何步降到 1/4 频率（EVERY4）就变成 **+3,009**，且 TD 从 **2.21 回到 1.28**（基线 1.20）⇒ `--pave_every` 是第一个该调的旋钮。
3. ❌ **M 侧罚项（MPR/VFC）单独用是危险的**，**四条**独立臂一致复现**梯度塌陷**：VFC（gscale 5.4e−06 / TD 19.67）、MPR（3.5e−06 / 39.71）、NOVFC（2.2e−07 / 1.85）、**NOCURV（1e−07 / 4.38 —— 反证锚点，最极端塌陷）**，成绩灾难（r1/块 −14,186 / −12,516 / −32.6 / **−747.1**，越界 44%/68%/10%/**23%**；NOCURV 的 t=−3.7、罚 928 元/块）⇒ **D14 的根因诊断（按当前 batch 归一化 ⇒ 损失对尺度免疫 ⇒ 把梯度压成 0）被四条臂坐实**。⇒ **"Curv 是必需的那一半"** 由此获得第 4 条独立证据（去掉 Curv 的 NOCURV 塌陷最严重，而它的 mpr/vfc 权重与 PAVE 完全相同）。
4. ✅ **Curv 是"有效且必需"的那一半**：curv 0.0224~0.05 时 μ 从 0.4% 抬到 20–34% **且拟合不坏**（TD 1.10–1.31），成绩同时显著变好 ⇒ 与理论 `L ≤ M/μ` 一致：**只压 M 会让 μ→0 把 L 炸掉；守住 μ 才换到成绩**。
5. ⚠ **μ 不是越大越好**：EVERY4 的 μ 75.7±15% 已超文献 PAVE 的 14–47%，但仍 +3,009；而 CURVONLY 的 μ 34.1% 拿到最低罚与最低越界 ⇒ **存在最优区间（≈20–50%）**，需要扫描确认。
