# 逐步奖励分解 critic（五步功率波动和）

按 `macro_critic_step_reward_decomposition_architecture.md` 实现，并适配到纯监督的
`F5 = Σ_{t=1..5} |P_t − P_{t−1}|` 预测任务。

## 1. 架构映射（文档 → 本实现）

| 文档模块 | 本实现 | 说明 |
|---|---|---|
| `MacroStateEncoder` | `1 → 64 → 64`，SiLU | 输入只有 `u1/10` |
| `MacroActionEncoder` | `5 → 64 → 64`，SiLU | 五维轴向因子 |
| FiLM | `(γ_s,β_s)=Linear(h_S)`；`h̃_o=(1+0.1γ_s)⊙h_o+0.1β_s` | 初始化为恒等调制 |
| 联合主体 | `z=[h_S;h_o;h̃_o]` (192) → 256 → 256(残差) → 128，SiLU | 与文档 §4.2 一致 |
| 逐步奖励头 | 共享头 `[z;e_t]`：128+16→64→1，SiLU；5 个阶段嵌入 `e_t∈R^16` | 预测 5 个 `|ΔP_t|` |
| 终端价值头 | `z→64→1`，SiLU | 纯预测任务没有下一宏状态 ⇒ 目标定义为 **0** |
| `QComposer` | `F5̂=Σ_t γ^t r̂_t + γ^f B̂`，默认 `γ=1` | 无可学习参数 |
| Replay | 静态 `aifflor_ua_f5.npz` | 保存 `p_steps/p_prev` 可还原逐步波动 |
| 训练目标 | `L=L_sum+λ_r L_r+λ_B L_B` | `L_sum` 是组合 F5 对真实 F5（替代无 TD 的 `L_Q`） |

**与文档的唯一实质差异**：文档的 `L_Q` 是宏 TD（需要下一宏状态与长期价值），
本任务是"给定 `u1,a` 直接预测五步波动和"，没有下一宏状态，所以：
- `L_Q` 退化为监督 `L_sum = Huber(F5̂ − F5)`；
- 终端头 `B` 的目标设为 0（无终端长期价值）；
- 若以后接回 RL，只需把 `B` 目标改为 `(1−done)·Q_target(S_next,π_target(S_next))`，
  并把 `L_sum` 换回宏 TD，结构不用改。

```
state u1/10 ─ 64 ─ 64 ─┐
                       ├─ FiLM ─→ z(192) ─→ 256 ─→ 256(+res) ─→ 128
action a(5) ─ 64 ─ 64 ─┘                                  │
                                                          ├─ 共享 reward 头 × 5 阶段 → r̂_t
                                                          └─ terminal head → B̂
F5̂ = Σ_t r̂_t + B̂
```

本实现有两个 `--arch`：
* `film`（默认）：文档原宽度，参数 **182,994**；3.1–3.4 的结果都是它。
* `per`：用户给定的 PER 隐藏层（`1→16→100→cat(a)→80→50`），参数 **14,460**；
  见 3.5 的专门对比。

## 2. 训练

- 数据：`aifflor_ua_f5.npz`（40k/5k/5k + 3k real，窗口级不重叠）。
- 逐步目标：`f_steps[:,0]=|P1−P0|`，`f_steps[:,t]=|P_{t+1}−P_t|`，`Σ=f5`。
- 损失：
  - `L_sum = Huber(F5̂ − F5, δ=1)`；
  - `L_r = mean Huber((r̂_t − r_t)/σ_t, δ=1)`，`σ_t` 为 train 每步波动标准差；
  - `L_B = Huber(B̂ − 0, δ=1)`；
  - `λ_r=1.0`、`λ_B=0.1`、`γ=1.0`。
- 优化：Adam `1e-3` 余弦到 `1e-4`，batch 256，梯度裁剪 2.0，30k 步上限，
  val F5 RMSE 早停。实测 best step **12,000**（val RMSE 3.1641），18k 早停，
  CPU 约 209 s（11.6 ms/step）。
- target 网络 `τ=1e-3` 软更新；纯监督不参与 loss，只作一致性检查。

### 3.2 逐步波动预测（test，5 个阶段）

**块和 F5 的误差并没有被逐步误差放大**：5 步误差部分抵消，F5 RMSE 3.10 MW。

### 3.5 PER 隐藏层变体（`--arch per`）

按用户给定的 PER 隐藏层替换共享 trunk，保留逐步分解：

```text
x=[u1/10] → Linear(1,16) → ReLU → Linear(16,100)（无激活）
          → cat(a) 105 → Linear(105,80) → ReLU → Linear(80,50) → ReLU → h(50)
逐步头: r̂_t = Linear([h; e_t])  (50+16 → 1)   × 5
终端头: B̂   = Linear(h)         (50 → 1)
F5̂ = Σ_t r̂_t + B̂
```

- 参数量 **14,460**（比 f5n 的 14,313 只多 147）；训练 4.11 ms/step，
  best step=6,000（val 3.1758），14k 早停，57.6 s。
- 结果：

| 方法 | 参数 | test R² | test RMSE | test MAPE | real RMSE | 梯度 pooled r | 余弦 mean/median | 斜率 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| **PER 隐藏层 step-decomp** | 14,460 | 0.482026 | 3.1083 | **41.29%** | 3.2503 | 0.6846 | 0.679 / 0.847 | 0.590 |
| FiLM step-decomp | 182,994 | 0.484646 | 3.1005 | 41.06% | 3.2384 | **0.8473** | **0.875 / 0.949** | 0.737 |
| monolithic `f5n` | 14,313 | **0.490380** | **3.0832** | 44.70% | **3.2202** | 0.8230 | 0.854 / 0.933 | **0.831** |

- test 配对 bootstrap：
  - `RMSE(PER) − RMSE(f5n) = +0.0251 MW`，95% CI `[+0.0076, +0.0419]` ⇒ **显著更差**；
  - `RMSE(PER) − RMSE(FiLM) = +0.0079`，CI `[−0.0050, +0.0206]` ⇒ 统计打平；
  - real 上 vs f5n `+0.0299`（CI `[−0.0029, +0.0609]`）、vs FiLM `+0.0120`（CI 跨 0）⇒ 都打平。
- 逐步波动（test）：t=0..4 的 R² 分别为 0.228 / 0.235 / 0.194 / 0.191 / 0.188，
  RMSE 1.177 / 1.115 / 1.189 / 1.203 / 1.179 MW；与 FiLM 版几乎相同。
- 终端头：test `mean|B|=0.0440`、real 0.0447，比 FiLM 版（0.050/0.052）更小。
- 梯度：pooled r 0.6846、余弦 0.679/0.847、斜率 0.590；`dim2/dim3` 尤其差
  （r 0.077/0.334，符号 0.698/0.486）。方向与幅度都不如 FiLM 版和 f5n。

⇒ **PER 隐藏层变体没有带来收益**：它把参数压到 14.5k、训练最快、MAPE 仍好，
但 test F5 RMSE 显著差于 f5n，梯度方向也明显弱于 FiLM 版。说明这个任务的
瓶颈不是"用不用 PER trunk"，而是**逐步预测头需要更大的共享表征/FiLM 调制**；
把 trunk 换小反而损失了容量。

### 3.6 终端头 B

纯预测任务中 `B` 的目标是 0；实测：

| split | mean | mean\|B\| | max\|B\| |
|---|---:|---:|---:|
| test | +0.0278 | 0.0497 | 0.1521 |
| real | +0.0310 | 0.0520 | 0.1666 |

`B` 很小（约 0.05 MW），没有抢走逐步头的信号；如果接回 RL，这个头才有
真正的"块末长期价值"含义。

## 4. 结论：这个架构够不够好？

**拟合精度**：
- FiLM step-decomp 的 F5 RMSE 比 monolithic `f5n` **差 0.017 MW（test，显著）**；
  **PER 隐藏层变体更差 0.025 MW（显著）**。real 上两者与 f5n 都打平。
- **纯 F5 预测上，f5n 仍然最好、也最小（14,313）**；PER 隐藏层变体 14,460
  参数、训练最快（4.1 ms/step），但没有换来精度。
- step-decomp 两个变体的 **MAPE 都更好**（41.1–41.3% vs 44.7%），且能给出
  5 个阶段的逐步预测，诊断性更强。

**梯度**：
- FiLM 版方向最好：pooled r 0.847 vs f5n 0.823，余弦 0.875/0.949 vs
  0.854/0.933，符号 0.839 vs 0.817；`dim0/dim4` 仍是最可靠的两维。
- FiLM 版幅度偏小 ~26%（斜率 0.737），需要步长校准；`dim1/dim2` 仍然弱
  （r 0.30/0.24，符号 0.815/0.698）。
- **PER 隐藏层变体的梯度明显更差**：pooled r 0.685、余弦 0.679/0.847、
  斜率 0.590；`dim2/dim3` 的 r 只有 0.077/0.334。把 trunk 换成 PER
  损失了逐步头需要的共享表征容量。

**架构本身的代价**：
- FiLM 版 183k 参数是 f5n 的 12.8 倍，训练更不稳定（val RMSE 在 3.16–3.24
  摆动，best 在 12k，18k 早停）；lr 降到 3e-4 没有改善 test（3.1006），
  反而让梯度更差（r 0.727、余弦 0.736）。
- PER 隐藏层版只有 14.5k 参数、训练最快，但 test 3.1083、梯度 r 0.685，
  是三个方案里最弱的（除 MAPE 外）。
- 逐步头单独看 R² 只有 0.19–0.24；块和靠误差抵消才到 0.48。

**建议**：
- 若目标是**纯 F5 拟合** → 继续用 `f5n`（14k 参数，test 3.0832）。
- 若目标是**逐步诊断 / 方向性梯度** → 用 **FiLM step-decomp**，但要做幅度
  校准（乘 ~1.36），并接受 test F5 略差 0.017 MW；**不建议 PER 隐藏层变体**，
  它的方向性梯度明显退化。
- 若目标是**接回 RL 的宏 critic** → 这个实现已经把结构搭好；把 `B` 的目标
  改成 `(1−done)Q_target`、`L_sum` 换回宏 TD，并保留 `L_r` 辅助损失，
  才是文档完整架构的真正用武之地。纯监督任务无法验证终端价值和宏 TD 的收益。

## 6. 局限

1. **纯监督适配**：没有下一宏状态，`B` 目标=0、`L_Q` 退化为 `L_sum`；
   文档的宏 TD / 终端价值收益无法在这个任务里体现。
2. **逐步波动本身噪声大**：`|ΔP|` 在风速平稳时接近 0，MAPE 不可靠；
   单步 R² 只有 0.19–0.24，块和靠误差抵消。
3. **梯度幅度**：step-decomp 的斜率 0.737，做梯度步需要乘 ~1.36；方向虽好，
   幅度不能直接用。
4. **容量/稳定性**：183k 参数在 40k 样本上偏大，val 摆动明显；没有做
   weight decay / 更小 joint 宽度的系统扫描（lr=3e-4 的对照反而更差）。
5. **窗口口径**：与 `README_fluct.md` 相同——`u0..u5` 同一个 `a`，
   只给 `u1`；不是 env 的"上一步动作"逐位复刻。
