# 五步功率波动和：`(u1, a) → F5 = Σ_{t=1..5} |P_t − P_{t-1}|`

## 任务定义

| 项 | 口径 |
|---|---|
| 标签 | `F5 = |P(u1,a) − P(u0,a)| + Σ_{t=2..5} |P(u_t,a) − P(u_{t-1},a)|` |
| 风速输入 | **只有窗口首步 `u1`**；`u0, u2..u5` 不喂网络 |
| 动作 | 两种口径：**5D 独立**（默认）或 **1D 同因子**（`--scalar_action`，`a_i=a0`）；`u0..u5` 上同一个动作 |
| 风速来源 | `FFC_speed_noise_1.csv` 同一列连续 5 行 + **前一行 `u0`** |
| 参考对照 | `F4 = Σ_{t=2..5}|…|`（窗口内 4 项，不含 `u0`） |

> 与 env 的关系：env 的 `P_F_1` 是 `|P(u1,a) − P_G_prev|`，其中 `P_G_prev` 来自
> **上一步动作**。本实验把 `u0` 那一步也固定成同一个 `a`，是为了做受控的
> "风速波动"归因；若要逐位复刻 env，需要再采样一个 `a_prev`。这一点在结论里
> 必须声明。

---

## 1. 数据

`make_dataset_fluct.py` 生成 **53,000** 个窗口（窗口级不重叠）：

| split | n | 采样 |
|---|---:|---|
| train | 40,000 | 合法 FFC 窗口 + `a~U(0,0.5)^5` |
| val | 5,000 | 独立窗口 |
| test | 5,000 | 独立窗口 |
| real | 3,000 | 独立窗口 + 5 种结构化动作族 |

* 合法窗口（`u0..u5` 全部在 `[3.5,25]`）：**273,971** 个。
* 两个数据文件：`aifflor_ua_f5.npz`（5D 独立动作）与
  `aifflor_ua_f5_scalar.npz`（1D 同因子，`--scalar_action`）。
* `F5∈[0.10, 45.08] MW`，均值 **6.84**、sd **4.38**；`F4` 均值 5.47；
  `F5/F4` 均值 **1.302**（第一项相对 `u0` 的波动约占 30%）。
* FLORIS 层 **0 坏点 / 0 兜底**。

### 可预测性：风速主导

只用 `u1` 的 `E[F5|u1]` 基线：

| split | R² | RMSE (MW) | MAPE |
|---|---:|---:|---:|
| test | 0.46946 | 3.1458 | 45.51% |
| real | 0.44950 | 3.3358 | 45.75% |

固定一个窗口、只变动作（50 个随机动作）时，`F5` 的 sd 约 **0.59 MW**，
而总体 sd 是 **4.38 MW** ⇒ 动作对波动和的解释力只有约 2%。
因此这个任务的 R² 天花板远低于五步功率和（0.887），**能到 ~0.49 已经说明
critic 抓到了那一点点动作信息**。

## 2. 探索过的方法

全部复用 PER 的 critic 结构（`1→hidden→hidden ∥ 5→80→50→1`）+ target
软更新；只改目标/输出参数化与容量。

| 代号 | 目标 | 预测还原 | 说明 |
|---|---|---|---|
| `f5` | `F5/10` | `×10` | 直接拟合波动和 |
| `f5u3` | `1000·F5/(5·u1³)` | `×5u1³/1000` | 用 `u1³` 做物理尺度 |
| `f5n` | `F5 / E[F5|u1]` | `×E[F5|u1]` | 去掉风速趋势；`E[F5|u1]` 由 train 分箱估计 |
| `f5n` 64/256 | 同上 | 同上 | 容量消融（41,829 参数） |
| ens3 | `(f5 + f5u3 + f5n)/3` | — | 三模型平均，检验集成收益 |
| baseline | `E[F5|u1]` | — | 只用 u1、动作无关 |

## 3. 结果

### 3.1 test / real（F5，MW）

| 方法 | test R² | test RMSE | test MAPE | real R² | real RMSE | real MAPE |
|---|---:|---:|---:|---:|---:|---:|
| `f5` 16/100 | 0.489974 | 3.0844 | **43.77%** | **0.489360** | 3.2128 | **43.65%** |
| **`f5u3` 16/100** | **0.491864** | **3.0787** | 44.39% | 0.486344 | 3.2222 | 44.40% |
| `f5n` 16/100 | 0.490380 | 3.0832 | 44.70% | 0.486991 | 3.2202 | 45.53% |
| `f5n` 64/256 | 0.488078 | 3.0901 | 44.22% | 0.488718 | 3.2148 | 44.21% |
| ens3 | **0.492163** | **3.0778** | 44.22% | 0.489899 | **3.2111** | 44.46% |
| baseline `E[F5|u1]` | 0.469456 | 3.1458 | 45.51% | 0.449504 | 3.3358 | 45.75% |

### 3.2 test 配对 bootstrap（5,000 点，5,000 次）

| 比较 | ΔRMSE | 95% CI | 结论 |
|---|---:|---|---|
| `f5u3` − baseline | **−0.0673** | [−0.0929, −0.0425] | 动作信息显著 |
| `f5n` − baseline | **−0.0628** | [−0.0849, −0.0409] | 动作信息显著 |
| `f5u3` − `f5n` | −0.0045 | [−0.0156, +0.0066] | 目标参数化打平 |
| `ens3` − `f5u3` | −0.0009 | [−0.0060, +0.0042] | 集成无显著收益 |

⇒ **所有单模型之间统计打平**；它们相对 `E[F5|u1]` 的 ~2% RMSE 改进是显著的，
说明 critic 确实学到了动作对波动的影响，但量级很小。

### 3.3 动作梯度 `∂F5/∂a`（test，400 点，δ=0.01）

| 方法 | pooled Pearson r | 斜率 | 中位相对误差 | 符号一致率 |
|---|---:|---:|---:|---:|
| `f5` 16/100 | 0.7973 | 0.8219 | 0.814 | 0.776 |
| `f5u3` 16/100 | 0.7909 | 0.8612 | 0.901 | 0.710 |
| **`f5n` 16/100** | **0.8230** | 0.8305 | **0.703** | **0.817** |
| `f5n` 64/256 | 0.7929 | 0.8654 | 0.725 | 0.830 |

`f5n` 的梯度综合最好；`f5u3` 斜率最高但符号一致率最差（0.71）。
所有方法的逐维梯度都受"给定 u1 后风序列未知"的噪声影响，dim1/dim2 仍最弱。

### 3.4 标量动作：一个 action 控五台（`--scalar_action`）

把动作改成 **1 维 `a0`，广播到 5 台**（`a_i=a0`），数据用
`make_dataset_fluct.py --scalar_action` 重新生成；网络 fc2 变成 `101→80`，
参数量 **13,993**。base=`f5`、`f5n` 各 40k 步重训。

| 方法（1D action） | test R² | test RMSE | test MAPE | real R² | real RMSE | real MAPE | 梯度 r / 斜率 / 符号 |
|---|---:|---:|---:|---:|---:|---:|---:|
| base `f5` | 0.549135 | 3.0370 | 46.32% | **0.506331** | **3.2223** | 45.38% | 0.8265 / 0.7084 / 0.8601 |
| **`f5n`** | **0.551351** | **3.0295** | **44.56%** | 0.503030 | 3.2331 | **44.16%** | **0.8610 / 0.7530 / 0.9364** |
| baseline `E[F5|u1]` | 0.404846 | 3.4893 | 61.81% | 0.433906 | 3.4506 | 46.84% | — |

test 配对 bootstrap：

```text
RMSE(f5)  − RMSE(f5n)  = +0.0076  [−0.0044, +0.0206]   ⇒ 打平
RMSE(f5n) − RMSE(base) = −0.4594  [−0.5029, −0.4158]   ⇒ 动作信息显著
RMSE(f5)  − RMSE(base) = −0.4526  [−0.4990, −0.4059]   ⇒ 动作信息显著
```

real 上 `f5n − base = −0.2180`（CI `[−0.2648, −0.1714]`），同样显著。

**和 5 维动作对比（注意：动作空间不同，不能逐样本配对）**：

| 项 | 5D 独立动作 | 1D 同因子 |
|---|---:|---:|
| `f5n` test RMSE / R² | 3.0832 / 0.4904 | **3.0295 / 0.5514** |
| baseline test RMSE | 3.1458 | 3.4893 |
| f5n 相对 baseline 的 RMSE 改善 | 0.0628 MW（2.0%） | **0.4594 MW（13.2%）** |
| f5n 梯度 r / 斜率 / 符号 | 0.823 / 0.831 / 0.817 | **0.861 / 0.753 / 0.936** |

⇒ **一个动作控五台时，动作对 F5 的影响变得更"相干"、更容易学**：
相对基线的改善从 2% 提到 13%，梯度符号一致率从 0.817 提到 0.936。
代价是幅度估计更保守（斜率 0.753，5D 是 0.831），做梯度步仍需放大。

逐族（f5n，1D）：`level` R²=0.521/RMSE 3.168，`cp_opt` 0.495/3.509，
`farm_opt` 0.441/3.222，`low` 0.527/2.731，`high` 0.456/3.474。
`cp_opt` 与 `high` 最难，符合"高轴向因子/强尾流区 F5 更非线性"的直觉。

## 4. 结论：什么是最好的方法

* **纯 test 拟合**：`f5u3` 的名义 RMSE 最低（3.0787 / R² 0.49186），但与
  `f5`（3.0844）、`f5n`（3.0832）**统计打平**；三模型平均 `ens3` 只再低
  0.0009 MW（CI 跨 0），不值得多训两个模型。
* **MAPE / real 拟合**：`f5` 最好（MAPE 43.77% / 43.65%，real RMSE 3.2128）。
* **动作梯度**：`f5n` 最好（r 0.823、符号 0.817），因此如果下游要按
  `∂F5/∂a` 做寻优，推荐 `f5n`。
* **容量**：64/256 没带来收益（test RMSE 3.0901，比 16/100 的 3.0832 还差），
  这个任务的瓶颈是风速噪声，不是网络容量。
* **动作空间比目标参数化更重要**：把 5 维独立动作换成 **1 个动作控五台**
  后，`f5n` 相对 baseline 的 RMSE 改善从 **0.063 MW（2%）变成 0.459 MW（13%）**，
  test R² 从 0.490 提到 **0.551**，梯度符号从 0.817 提到 **0.936**。
  原因是一个共同轴向因子对五台/尾流是“相干”影响，比 5 维独立动作更容易学。
* **推荐**：
  - 若实际控制允许“五台同因子” → 用 **1D action + `f5n`**：
    test RMSE 3.0295 / R² 0.5514 / MAPE 44.56%，梯度 r 0.861、符号 0.936；
    这是本任务目前**综合最好**的配置。
  - 若必须 5 维独立动作 → 要一个综合最稳的直接 F5 critic 用 `f5n` 16/100
    （梯度最好，拟合与 f5/f5u3 打平）；只看 test RMSE 用 `f5u3`；
    只看 MAPE / real 用 `f5`。
  - 不建议 64/256 或三模型集成（收益不显著）。
* **最重要的结论**：5D 动作下 `F5` 的 R² 只有 ~0.49，不是网络不行，而是
  **只给 u1 时风速窗口的逐点差异不可约**；critic 能把 `E[F5|u1]` 基线再降
  ~0.063–0.067 MW（显著，约 2%），这部分才是动作信息。换成 1D 同因子后，
  可学习的那部分动作信息变大（13%），但 R² 仍只有 0.55，风速噪声仍是主体。

## 6. 口径与局限

1. **`u0` 的动作**：本实验让 `u0..u5` 共用一个 `a`。env 的真实 `P_G_prev`
   来自上一步动作，若要逐位对齐，应再采样 `a_prev`；当前结果是"纯风速波动"
   的受控归因。
2. **只看 `u1`**：`u0` 与 `u2..u5` 不喂网络；第一项 `|P1−P0|` 的 `u0` 未知，
   是标签噪声的一部分。
3. **窗口过滤**：只保留 `u0..u5` 都在 `[3.5,25]` 的窗口；切出/停机边界不在
   本实验。
4. **参考基线不是严格上界**：`E[F5|u1]` 是 0.5 m/s 分箱均值，动作无关；
   模型小幅优于它是正常的。
5. **梯度**：真值是实际 5 步序列上的割线；网络是条件均值梯度。`dim1/dim2`
   仍弱，若要逐台寻优，建议 `f5n` + 局部 aifflor 差分校准。
6. **未尝试**：对同一 `(u1,a)` 采样 K 条窗口平均目标（降标签噪声）、
   对 `F5` 加 Sobolev 梯度正则、或把 `E[F5|u1]` 做平滑（样条/多项式）。
