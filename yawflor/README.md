# YAWFLOR — 偏航控制 + FLORIS 新环境（**方案，待执行**）

> **本目录当前只有本文件，没有一行代码。** 本文件是执行前的方案与验收锚，
> 经确认后才按 §6 开工。所有实测数字都来自只读探针
> `agentutil/probe_floris_yaw_structure.py`（11 节），证据索引见 §9。

**一句话**：沿用现有 HSRL 的分层结构（H 每 5 min 决策 / L 每步调度 BESS），
把**被控对象**从"5 维轴向因子 + WFSim"换成"**5 维偏航角 + FLORIS**"，
轴向因子**固定 a = 1/3**；风机、布局、电价、储能、奖励函数全部不变。
主目标：**波动控制条件下的盈利最大化**（波动控制优先）。

**与现有 9 个方法的关系**：不是新算法，是**同一算法的第二个动作空间 / 第二个物理引擎**。
基线选 `td3per`（上层 TD3 + 下层 RL BESS，理由：双层 RL 都在，能同时检验下层在新功率量级下的表现）。
**跨引擎的 profit 不可直接比较**（FLORIS 电平是 WFSim 的 1.74×，见 §3），
只能同轨比较或归一化后比较。

## 1. 核心张力：能量与波动**同比放大**（本方案的立论）

FLORIS 里偏航转向增益 +46%，但**绝对波动也同比放大 46%**，而并网限值 3 MW 是**绝对值**
⇒ "多发电"和"压波动"直接对抗。这就是本项目要的张力，也是新方法与旧环境最本质的差别。

### 表 A｜带端点：H 层的物理权限（真实风速日 1440 min）

| 工作点 | 平均功率 | 全天电量 |
|---|---|---|
| γ≡0（不转向） | 3.988 MW | 95.715 MWh |
| **γ\*（最优转向）** | **5.835 MW** | **140.050 MWh（+46.3%）** |
| 带内最劣（只转末台 25°） | 3.882 MW | 93.176 MWh（−2.7%） |

⇒ H 层相对工作点 γ\* 的**下探余量 = 33.5%**（5.835 → 3.882 MW）。这是它做平抑的全部物理权限。
> ⚠ 注意：相对 γ≡0 的下探只有 2.7% —— 说"偏航能削减"时必须指明**相对哪个工作点**。

### 表 B｜转向档位 s（γ = s·γ\*）：**验收锚曲线**（1440 min）

| s | 全天电量 | 增益 | \|ΔP\| 均值 | p95 | p99 | max | 超 3 MW 占比 |
|---|---|---|---|---|---|---|---|
| 0.00 | 95.715 MWh | +0.0% | 1.447 | 4.07 | 6.71 | 11.34 | **11.74%** |
| 0.25 | 106.946 | +11.7% | 1.618 | 4.52 | 7.50 | 12.64 | 15.15% |
| 0.50 | 124.039 | +29.6% | 1.877 | 5.28 | 8.72 | 14.70 | 19.04% |
| 0.75 | 134.828 | +40.9% | 2.041 | 5.74 | 9.47 | 15.98 | 21.68% |
| 1.00 | 140.047 | +46.3% | 2.120 | 5.97 | 9.85 | 16.63 | **22.79%** |

电量 ×1.463 与 \|ΔP\| 均值 ×1.465 —— **几乎完全同比**。**任何策略都必须打在这条曲线上**：
"能量更高且波动更低"的点不存在，只能选折中位置。

### 表 C｜偏航单独能做到的平滑地板（目标 = 上一分钟 P_w，与 `c1` 定义一致）

| 口径 | \|ΔP\| 均值 | p99 | max | 超 3 MW 占比 | 全天电量 |
|---|---|---|---|---|---|
| γ\* 原始（不平抑） | 2.120 | 9.84 | 16.62 | 22.86% | 140.05 MWh |
| **理想 H**（每分钟可调，能力上界） | **1.076** | 5.21 | 9.39 | **7.78%** | — |
| **H 层 5-min 粒度**（每块一个 s，贪心，**现实门槛**） | **1.727** | 8.18 | 15.42 | **17.16%** | 122.63 MWh（+28.1%，s 均值 0.58） |

- 偏航**完全抹平** 28.6% 的分钟步；**残留均值 1.286 MW / p99 7.674 MW** 只能交给电池
  （电池 ±10 MW / **6 MWh = 满功率仅 36 min**）。
- **表 C 第 3 行就是 RL 要打败的真实门槛**（不是 s≡1 那条静态曲线）：
  一个简单贪心调度已能把超限率 22.9% → 17.2%，代价 12.4% 电量。RL 的增量必须相对它度量。

| 轴向因子 | **固定 a = 1/3**（Betz 单机最优点），不作为动作 |

## 4. 动作口径与先验常量（**单一真源，禁止散落**）

网络动作保持**无量纲归一化** `n ∈ [−1, +1]`（env 内转 `γ = 25°·n`），
使旧环境每个常量的"占带宽度比例"原样平移 —— 这是为了避免重犯 README 记录过的
两轮"先验位置写错"（先验只编码**单机物理**，风场最优交给策略）。

| 常量 | 旧（a，带宽 0.5） | 新（n，带宽 2） | 换算原则 |
|---|---|---|---|
| `hsrl_warmup.WT_START` | 1/3 | **0** | 单机最优点（γ=0 自损最小） |
| `hsrl_warmup.WT_LO, WT_HI` | 0.05, 0.45 | **−1, +1** | 中性满带 |
| `hsrl_warmup.WT_STEP` | 0.05 | **0.2** | 带宽的 10%（实测最优轨迹 p99 跳变 5.5° ≈ 5°，自洽） |
| `init_wt_action_bias(lo, hi)` | 0.05, 0.45 | **−1, +1** | 与 warmup 同分布（不变量保留） |
| 探索噪声 `--wt_noise` | 0.05 | **0.2** | 带宽的 10% |
| `hsrl_cost.PENALTY_NN_H_COEF` | 400（满带越界 = 200 元） | **100** | 满带越界仍是 200 元 |
| `env.{reset,TestReset,ScenarioReset}` 标称动作 | 0.3333 | **0** | `P_G_prev` 波动基准取单机物理点 |
| λ1 构造 `LAM_MIN = RHO_S·PR_REF·DT` | 0.967 元/MW·step | **不改** | 是"每 MW"口径，与风场电平无关（见 §7 饱和核查） |

**执行器约束常量**（默认**关**，位置留好）：

| 常量 | 默认 | 依据 |
|---|---|---|
| `YAW_RATE_MAX_DEG_PER_BLOCK` | `None`（不限制） | 实测：最优轨迹跳变 p99 = 5.5°；Δmax=10°/块只损失 0.05% 电量（2/288 块受限）。默认关 = 与文献口径一致 |
| `YAW_TAU_S`（一阶延迟） | `0`（关） | 5.5° @0.3 °/s 仅需 18 s（占 5 min 的 6%） |
| `YAW_TRANSPORT_DELAY` | `off` | 开启即 env **有记忆**，会破坏 test9 的确定性判据 + `probe_wfsim_memoryless` 认证的性质 ⇒ 只能作对照臂 |

## 7. 评测协议（波动控制优先）

**主指标顺序**：`viol_count` → `viol_excess_mw` → `profit_rmb`（与 `test_five_days.py`
的 `DAY_METRICS` 一致，不需要改代码，只改报告口径与结论顺序）。

**4 条基线臂**（RL 的增量必须相对它们度量，同时回答审稿人的"RL 增量是什么"）：

| 臂 | 定义 | 实测锚（1440 min） |
|---|---|---|
| B1 | `s ≡ 0`（不转向） | 95.715 MWh / 超限 11.74% |
| B2 | `s ≡ 1`（常数最优转向） | 140.047 MWh / 超限 22.79% |
| B3 | `s ≡ 中间档`（波动感知的静态折中，如 0.5） | 124.039 MWh / 超限 19.04% |
| **B4** | **`s` 块级规则调度（5-min 粒度贪心）** | **122.625 MWh / 超限 17.16%** ← **RL 的主要门槛** |

> B1–B4 都在表 B/C 的**同一条折中曲线**上，彼此不构成支配关系（B3 电量高 1.4 MWh、
> 但超限率也高 1.9 pp）。因此判据是**平面支配**，不是单指标比大小。

**P5 通过判据（硬性）**：至少一个 `yawflor` run 在 **(全天电量, >3 MW 超限率)** 平面上
**支配 B4**（电量 ≥ 122.6 MWh **且** 超限率 ≤ 17.2%），且不劣于 B1/B2/B3 中任一臂的对应点。
若做不到 ⇒ 说明"波动优先"的目标下 RL 未跑赢规则调度，必须如实报告（这本身也是有价值的结果）。

**必须报告的附加项**：
1. **λ1 轨迹与饱和占比**：新环境波动 ×1.46、约束相对更紧，λ1 可能长期顶在 `LAM_MAX=4.833`。
   若饱和 ⇒ "平抑支付意愿"上界按旧环境定低了，需在新环境重设（**这是唯一可能需要改的常量**）。
2. 学到的**偏航形态**（上游 vs 下游角度剖面）与探针逐台最优 `[25,25,12.5,6.25,0]` 的对照。
3. **逐块 s 的时间序列**（对照表 C 的 5-min 贪心调度），说明策略是在"择时"还是"常数"。

## 8. 风险登记与**明确不做**

| # | 风险 | 处置 |
|---|---|---|
| R1 | 增益量级强依赖尾流模型（+13% ~ +43%，甚至 −12%） | §2 敏感性表进论文；主臂 GCH（与文献/FLORIS 默认一致），其他模型作对照 |
| R2 | GCH 的 `enable_transverse_velocities` 使 `P(+γ) ≠ P(−γ)` 约 **+1.84%**（关掉后**精确为 0**，但转向增益从 +42.8% 掉到 +9.7%） | **主臂不改**（保持 FLORIS 原始口径以便与文献对照）+ 文档明写该偏置 + 预留 `--yaw_symmetrize`（`P_sym = ½[P(γ)+P(−γ)]`）作对照臂 |
| R3 | 全场同向 \|γ\| ≥ 45° 时 `gauss` 挠曲模型出 **NaN**（`wake_deflection/gauss.py:189`） | env 必须做有限性守卫（P1 验收④）；±25° 带内安全 |
| R4 | 绝对电平 ×1.74 ⇒ 跨引擎 profit 不可比；3 MW 限值相对更紧 | 文档红字声明；跨轨只比归一化指标（MWh、超限率） |
| R5 | "常数最优偏航就能拿 +46%" ⇒ RL 贡献被质疑 | §7 的 B1–B4 四条臂；贡献落在"**能量×波动×电池退化**的时序权衡"上，不落在"找到转向最优" |
| R6 | 稳态假设忽略渐变（执行器 18 s / 输运 200~333 s / 尾流重建） | 默认不建模（与文献口径一致）；**量化已做**：最优命令后移 10D/U(2.17 min)/20D/U(4.33 min) 电量只差 **−0.00% / −0.01%**（因最优偏航几乎时不变）；仅当策略把偏航当快速执行器来回摆时该假设才变弱 ⇒ P5 用策略自身偏航序列复算该偏差 |

**明确不做**：结构载荷/疲劳建模、偏航执行器一阶延迟（默认关）、尾流输运延迟（默认关）、
额定功率上限、风向时变（风剪切/风向序列）、FAST.Farm/SOWFA 类动态求解器、
把模型切换当主臂（只作敏感性）。
