# YAWFLOR — 偏航控制 + FLORIS 新环境（**方案，待执行**）

> **本目录当前只有本文件，没有一行代码。** 本文件是执行前的方案与验收锚，
> 经确认后才按 §6 开工。所有实测数字都来自只读探针
> `agentutil/probe_floris_yaw_structure.py`（11 节），证据索引见 §9。

**一句话**：沿用现有 HSRL 的分层结构（H 每 5 min 决策 / L 每步调度 BESS），
把**被控对象**从"5 维轴向因子 + WFSim"换成"**5 维偏航角 + FLORIS**"，
轴向因子**固定 a = 1/3**；风机、布局、电价、储能、奖励函数全部不变。
主目标：**波动控制条件下的盈利最大化**（波动控制优先）。

**与现有 9 个方法的关系**：不是新算法，是**同一算法的第二个动作空间 / 第二个物理引擎**。
基线选 `td3per`（上层 TD3 + 下层 RL BESS，理由：双层 RL 都在，能同时检验下层在新功率量级下的表现）。
**跨引擎的 profit 不可直接比较**（FLORIS 电平是 WFSim 的 1.74×，见 §3），
只能同轨比较或归一化后比较。

## 1. 核心张力：能量与波动**同比放大**（本方案的立论）

FLORIS 里偏航转向增益 +39%，但**绝对波动也同比放大 39%**，而并网限值 3 MW 是**绝对值**
⇒ "多发电"和"压波动"直接对抗。这就是本项目要的张力，也是新方法与旧环境最本质的差别。

> 本节（及 §7）的全部锚表按**官方口径 `wind_shear = 0.12`** 实测（见 §2 的说明：
> 切变是一阶口径项，关掉它会把增益从 +37% 抬到 +43%）。
> 切变取 0 的那一套数字见 §2 的敏感性小节，两者定性结论完全一致。

### 表 A｜带端点：H 层的物理权限（真实风速日 1440 min）

| 工作点 | 平均功率 | 全天电量 |
|---|---|---|
| γ≡0（不转向） | 3.955 MW | 94.917 MWh |
| **γ\*（逐块最优转向）** | **5.503 MW** | **132.063 MWh（+39.1%）** |
| 带内最劣（只转末台 25°） | 3.851 MW | 92.424 MWh（−2.6%） |

⇒ H 层相对工作点 γ\* 的**下探余量 ≈ 30.0%**（5.503 → 3.851 MW；若用固定高模式
`[25,25,12.5,6.25,0]` 则为 28.9%）。**这是它做平抑的全部物理权限。**
> ⚠ 注意：相对 γ≡0 的下探只有 2.6% —— 说"偏航能削减"时必须指明**相对哪个工作点**。

|---|---|---|---|---|---|---|---|
| 0.00 | 94.917 MWh | +0.0% | 1.434 | 4.04 | 6.66 | 11.25 | **11.61%** |
| 0.25 | 102.484 | +7.97% | 1.550 | 4.34 | 7.20 | 12.10 | 14.11% |

电量 ×1.391 与 \|ΔP\| 均值 ×1.394 —— **几乎完全同比**。**任何策略都必须打在这条曲线上**：
"能量更高且波动更低"的点不存在，只能选折中位置。

### 表 C｜偏航单独能做到的平滑地板（目标 = 上一分钟 P_w，与 `c1` 定义一致）

|---|---|---|---|---|---|

- **表 C 第 3 行就是 RL 要打败的真实门槛**（不是 s≡1 那条静态曲线）：
  一个简单贪心调度已能把超限率 20.3% → 16.0%，代价 11.0% 电量。RL 的增量必须相对它度量。

### 2.2 口径敏感性（**入场券 4**：主结果必须附）

**（a）尾流/损失模型**（u=10、前 4 台 +25°、末台 0°、`wind_shear 0.12`）

| 口径 | γ=0 基线 | 固定模式\* | 增益 |
|---|---|---|---|
| **GCH（主臂）** | 5.9423 MW | 8.1655 MW | **+37.41%** |
| jensen + jimenez | 6.3268 | 7.4070 | **+17.07%** |
| turboparkgauss + gauss | 4.7617 | 4.0267 | **−15.44%** |
| GCH + `cosine_loss_exponent_yaw = 3.0` | 5.9423 | 7.4961 | +26.15% |

（同表在 `wind_shear = 0` 下为 **+42.77% / +13.32% / −12.42% / +31.11%**；两套的定性结论一致。）

**（b）风切变**（`wind_shear`，**一阶项**）

| `wind_shear` | γ=0 基线 | 固定模式 | 增益 | 全天电量（逐块最优） |
|---|---|---|---|---|
| 0（2D WFSim 口径） | 5.9918 MW | 8.5543 MW | +42.77% | 140.047 MWh |
| **0.12（官方默认，本方案主臂）** | 5.9423 | 8.1655 | **+37.41%** | **132.063 MWh** |

> ⚠ 切变还带来一个**必须知道的副作用**：`shear ≠ 0` 时"隔离机组的功率 = 轮毂风速解析式"
> 这条不变量**失效**（实测比值 **0.995555**，即 −0.44%）。原因是 FLORIS 在转子盘上按
> `u_eff = cbrt(mean(u³))` 平均切变剖面，而解析式用的是轮毂风速 ——
> **功率表的自变量是 `u_eff` 而不是轮毂风速**。表本身仍与解析式逐点一致（偏差 0），
> 所以这是"定义域的差别"而不是"标定误差"。`agentutil/test_yawflor_config.py` 已把
> `shear=0` 的逐位断言与 `shear=0.12` 的比值报告分开，避免被自己的不变量骗到。

**（c）机型功率曲线 + 密度**（零阶项）

| 口径 | 基线与增益（同一 5 台 5D 单排、TI 0.06、shear 0.12） |

| 本方案（常数 Cp=0.563、D=100、ρ=1.20） | u=10：基线 5.9423 MW，固定模式 **+37.41%** |
| **官方参考机 `nrel_5MW`**（D=125.88、ρ=1.225，5 台 629.4 m 间距） | u=8：3.9139 MW → **+35.13%**；u=10：7.7072 → **+34.10%**；u=12：13.0959 → **+34.87%** |

⇒ **"理想化常数 Cp"（最无文献先例的一行）对本结论只值 2.5 pp**，而模型选型值 50 pp。

| 布局 | 单排 3~5 台、**6~8D** | 单排 5 台、**5D** | ⚠️ 比众数紧 ⇒ 增益偏高（§2.2(d) 已量化） |
| 更新周期 | 现场 1~2.5 h / 10 min；RL 论文按 step | 5 min | ⚠️ **比所有现场先例都快**；但实测最优轨迹几乎时不变（§2.2 之外，见 §8 R6），慢下来几乎不损失 |

**（c）两个真缺口，各自的处置**

1. **理想化常数 Cp（a≡1/3）在 FLORIS 文献里查无先例**（调研结论 D）：相邻传统只有
   `cos^p(γ)` 偏航损失模型（Fleming 2017 拟合 p=1.41；Howland 2022 测 cos³γ）——但那是乘在
   **真实功率曲线**上的；以及 LES 里的**固定诱导执行器盘理想化**与解析风场模型里的常数 Ct 机。
   **处置**：① 主臂保留（它同时满足"与旧环境同算例"和"把动作变量隔离为唯一变量"两条），
   但必须**从第一性原理说明**（理想 Betz 执行器盘、定桨距 a=1/3）而**不是引用**；
   ② 附 §2.2(c) 的 NREL 5MW 敏感性（**只差 2.5 pp**）作为答复；
   ③ 预留逃生门：主臂整体切 `turbine_type=['nrel_5MW']` 只需改一处（`yawflor_turbine.py`），
   代价是 §1 锚表全部重测（一次 2.5 min 的探针运行）。
2. **5D 间距**（比模态 6~8D 紧）：不是缺陷而是**算例定义**（来自 `meshing.m`），
   但**引用文献增益时必须并列间距**；§2.2(d) 的表就是为此准备的。

## 4. 动作口径与先验常量（**单一真源，禁止散落**）

网络动作保持**无量纲归一化** `n ∈ [−1, +1]`（env 内转 `γ = 25°·n`），
使旧环境每个常量的"占带宽度比例"原样平移 —— 这是为了避免重犯 README 记录过的
两轮"先验位置写错"（先验只编码**单机物理**，风场最优交给策略）。

| 常量 | 旧（a，带宽 0.5） | 新（n，带宽 2） | 换算原则 |
|---|---|---|---|
| `hsrl_warmup.WT_START` | 1/3 | **0** | 单机最优点（γ=0 自损最小） |
| `hsrl_warmup.WT_LO, WT_HI` | 0.05, 0.45 | **−1, +1** | 中性满带 |
| `hsrl_warmup.WT_STEP` | 0.05 | **0.2** | 带宽的 10%（实测最优轨迹 p99 跳变 5.5° ≈ 5°，自洽） |
| `init_wt_action_bias(lo, hi)` | 0.05, 0.45 | **−1, +1** | 与 warmup 同分布（不变量保留） |
| 探索噪声 `--wt_noise` | 0.05 | **0.2** | 带宽的 10% |
| `hsrl_cost.PENALTY_NN_H_COEF` | 400（满带越界 = 200 元） | **100** | 满带越界仍是 200 元 |
| `env.{reset,TestReset,ScenarioReset}` 标称动作 | 0.3333 | **0** | `P_G_prev` 波动基准取单机物理点 |
| λ1 构造 `LAM_MIN = RHO_S·PR_REF·DT` | 0.967 元/MW·step | **不改** | 是"每 MW"口径，与风场电平无关（见 §7 饱和核查） |

**执行器约束常量**（默认**关**，位置留好）：

| 常量 | 默认 | 依据 |
|---|---|---|
| `YAW_RATE_MAX_DEG_PER_BLOCK` | `None`（不限制） | 实测：最优轨迹跳变 p99 = 5.5°；Δmax=10°/块只损失 0.05% 电量（2/288 块受限）。默认关 = 与文献口径一致 |
| `YAW_TAU_S`（一阶延迟） | `0`（关） | 5.5° @0.3 °/s 仅需 18 s（占 5 min 的 6%） |
| `YAW_TRANSPORT_DELAY` | `off` | 开启即 env **有记忆**，会破坏 test9 的确定性判据 + `probe_wfsim_memoryless` 认证的性质 ⇒ 只能作对照臂 |

## 7. 评测协议（波动控制优先）

**主指标顺序**：`viol_count` → `viol_excess_mw` → `profit_rmb`（与 `test_five_days.py`
的 `DAY_METRICS` 一致，不需要改代码，只改报告口径与结论顺序）。

**4 条基线臂**（RL 的增量必须相对它们度量，同时回答审稿人的"RL 增量是什么"）：

| 臂 | 定义 | 实测锚（1440 min，`wind_shear = 0.12`） |
|---|---|---|
| B1 | `s ≡ 0`（不转向） | 94.917 MWh / 超限 11.61% |
| B2 | `s ≡ 1`（逐块最优转向，能量上界） | 132.063 MWh / 超限 20.92% |
| B3 | `s ≡ 中间档`（波动感知的静态折中，取 0.5） | 115.625 MWh / 超限 17.30% |
| **B4** | **`s` 块级规则调度（5-min 粒度贪心）** | **117.486 MWh / 超限 15.98%** ← **RL 的主要门槛** |

> **B4 已支配 B1 与 B3**（电量更高 **且** 超限率更低）⇒ 只打败静态档位不算成绩。
> 唯一不被 B4 支配的是 **B2**（能量高 14.6 MWh、超限率高 4.9 pp）—— RL 必须在这个
> "能量-超限" 交换上给出比 B4 更好的点，或明确报告它选择了哪个交换。

**P5 通过判据（硬性）**：至少一个 `yawflor` run 在 **(全天电量, >3 MW 超限率)** 平面上
**支配 B4**（电量 ≥ 117.5 MWh **且** 超限率 ≤ 16.0%）。
若做不到 ⇒ 说明"波动优先"的目标下 RL 未跑赢规则调度，必须如实报告（这本身也是有价值的结果）。

**必须报告的附加项**：
1. **λ1 轨迹与饱和占比**：新环境波动 ×1.39、约束相对更紧，λ1 可能长期顶在 `LAM_MAX=4.833`。
   若饱和 ⇒ "平抑支付意愿"上界按旧环境定低了，需在新环境重设（**这是唯一可能需要改的常量**）。
2. 学到的**偏航形态**（上游 vs 下游角度剖面）与探针逐台最优 `[25,25,12.5,6.25,0]` 的对照。
3. **逐块 s 的时间序列**（对照表 C 的 5-min 贪心调度），说明策略是在"择时"还是"常数"。
