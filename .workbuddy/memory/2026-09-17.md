## TD3PER 上层不收敛诊断（纯分析，未改代码）

分析了 td3per/（main/ddpg/myfunc）与 model.py，并用 output/TD3PER-run2 的 CSV 佐证。核心结论：

1. **下层非平稳是主因**：H 的 r1=pr·P_G·dt 与 c1(P_F) 都经由 pbrule 依赖 L 的实时策略；L 在学习 ⇒ H 的 MDP 非平稳。td3perrb（规则下层）平稳可收敛，差异仅在 L。
2. **lam2 贴死 500**（实测）：c2_slack 均值 0.0208 MWh/step ⇒ sum_c2≈104/块 ≫ d_block_L=20，对偶退化为常数，r2 梯度被 −500·Q_c 淹没。
3. **lam1 全程 3↔100 震荡**（实测 run2：5→55.8→3，min3/max100）：H 的目标权重反复改写 30 倍。
4. **a6(SOC 信号) 信用路径完全经由 L**：L 不成熟时 ∂r1/∂a6≈噪声；且 sig_noise_min=0.05 永久地板 ⇒ soc_target 永远抖 ±0.25 MWh。
5. **WT 探索 20k 步即关**（--epsilon 4000 决策），占 144 万步训练的 1.4%；之后只剩 prate=1e-4 的 DPG 漂移。
6. **PER 放大陈旧高 TD 样本**：非平稳来源的高 TD transition 被反复采样；H buffer 20000 ≈ 70 个 episode 的块级 transition，陈旧度高。
7. run2 仅 38 episode（~4% 训练量），bess_profit 持续约 −20k/episode，clip_amount>0 占 24% 步。

改进方向：L 先做 SocTracker BC 预训练/冻结再联训；缩小 H buffer 或降 PER α；放宽 d_block_L 或降 ema_lam_lr；延长 --epsilon；训练后期取消 sig_noise_min。

注：本机 bash 环境 coreutils 缺失（ls/wc/mkdir 均 127），须用专用工具或 managed python。

## 修正（用户补充：td3perrb 规则下层同样不收敛 ⇒ 下层非平稳不是根因）

用 TD3PER-run2 数据重新定位，根因在 H 层自身（td3per/td3perrb 共用同一套 H 栈）：

1. **Critic 价值发散（主因）**：update_stats_H.csv 显示 Q_p 153→1193（8× 持续膨胀）、td_p 39→327 不减反增；Q_c 24→69 与实际成本下降背离；PER IS 权重 0.41→0.07 塌缩（采样集中少数高 TD 样本，正反馈）。actor 在不断变形的 Q 曲面上爬升 ⇒ 9-case 固定场景利润峰后回落（~5900@32k 步 → 漂移 3000~4200）。
2. **Actor 全程持续越界**：original_action_H 越界率 18%~36% 五段不降，penalty_NN_H 13~43/决策；线性输出 actor 无边界 + buffer 存未裁剪动作 + 惩罚写进 r1 的"恒定恢复力"设计 ⇒ 策略永远悬在边界外被裁剪扰动。
3. **lam1 bang-bang**：早期 EMA≫d 撞顶 100（d 被课程减到 5-6.25），随后 EMA≪d 缓慢回落，末段 40% 时间钉死地板 3（最长连续 2227 块）；lam 几乎不在中间工作点。早期是主因之一，后期让位于 Q 发散。
4. **信号维结构性弱梯度**（td3prrlrb README 风险点 2 已自述）：规则每块 ±0.25 MWh vs 信号跨度 5 MWh，有效动作区间仅 6-10%；sig_noise_min=0.05=±0.25 MWh 目标抖动恰好淹没有效信号。
5. episode_reward 摆动大部分是随机风日的外生方差，不能当收敛判据；应用 df_test9 固定场景。

改进清单（H 内）：r1 缩放或 γ 0.9-0.95 / Q target clamp / layer-norm；PER priority clip + α 0.4；actor 加 tanh 有界输出、buffer 存 applied action；lam 区间收窄/降 ema_lam_lr 或 gap 罚挪回 r1 固定权重；a6 改增量式目标 soc_target=clip(E+Δ,带)，Δ∈±0.25。

## 再研究（第三轮）：环境侧三重结构性障碍（解释"为什么偏偏是风机维学不会"）

实测（TD3PER-run2 数据）：

1. **WT 维信噪比极低**：分风速段回归 ptur ~ action 各维：u<8 时单维边际效应 ≈ 0（±0.01 MW/0.1 动作，低风时 WT 维是纯噪声维，漂移不受约束）；u≥11 时也只有 0.1~0.7 MW/0.1，折即时奖励最多 ~11 元/步 vs r1 步级波动 ±400 元 → 即时信噪比 1-3%。且各维梯度符号跨风速/跨维不一致（d2 恒负 vs d0/d1/d4 恒正——尾流转向物理所致），5 维响应面病态。
2. **电池吸收效应**：corr(dptur,dpb)=0.61 vs corr(dptur,dpg)=0.27 → 风机功率变化 ~61% 被电池吸收，r1=pr·P_G·dt 只继承 27%；WT 维的真实回报必须经 SOC→未来电价→∂V/∂SOC 延迟回流，而 Q 膨胀时 SOC 定价最不可靠。规则下层 SocTracker 本职就是吸收盈余 ⇒ 换下层无效（与用户观察一致）。
3. **日界 done 截断**（td3per_main.py:374-380）：1440 步是时间限制却存 done=True → bootstrap 午夜砍断；γ=0.99/块使失真前传 ~100 块 ≈ 8h，覆盖整个晚高峰→低谷过渡；每天风日随机使失真符号每天不同 → 傍晚段价值目标持续抖动。
4. **观测的可辨识性**（原"加 ptur/10 进观测"建议已被用户指出错误并作废）：当前块 ptur=f(u,a) 是动作函数，决策前不可得，循环依赖。合法替代：① ptur_prev（上块实现功率，因果合法，可把 P_G_last 分解为 ptur_prev−pb_prev，解开电池吸收的混淆）；② a_{t-1}（上块 applied action，否则 ptur_prev 无法归因到动作）；③ 可选 P_ref(u)=f(u,a_ref) 固定参考动作功率（无循环依赖，代价每块多一次 WFSim 调用）。另注意：critic 输入本来就含 (u,a)，f(u,a) 可由 Q 网络内部学习，问题在观测层面风资源 vs 电池吸收的可辨识性，不在 critic 反演。

新增修复项：episode 末 done=False（TimeLimit bootstrap，一行改动）；观测加 ptur_prev + a_{t-1}。结论：WT 不收敛 = 算法侧（Q膨胀/越界/lam/PER）× 环境侧（低信噪比+电池吸收+日界截断）；SOC 信号维至少有 gap 罚即时反馈，WT 维连即时反馈都被电池吸收。

注：tanh 输出极端化的对策已答用户：pre-tanh L2 正则（1e-3·z²）+ 中点 bias 初始化 + 先止血 Q 膨胀再上 tanh + buffer 存 applied 并删 penalty 通道。γ=0.95 视野问题已答：跨天套利靠 V(SOC,phase) 价值接力而非单步视野，验证方法=9-case 行为方向 + 固定 phase 扫 SOC 画 Q。
